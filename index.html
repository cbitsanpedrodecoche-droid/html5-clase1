🤔 ¿Qué es HTML?

HyperText Markup Language

🚫

No es programación

Es un lenguaje de etiquetas: describe qué hay en la página, no qué hacer con ella.

🏠

Como una casa

HTML son los muros y las habitaciones. Los muebles y la pintura vienen después.

👨‍🔬 1991 · El nacimiento

🧪

Tim Berners-Lee

Un físico, no un informático, trabajando en el CERN (Suiza).

💡

Su idea

Compartir documentos científicos entre investigadores de todo el mundo.

🧰

Inventó TODO

HTML + HTTP + URL + el primer navegador. Cuatro piezas, una revolución.

🎉 La primera página web sigue online: info.cern.ch

Cada uno inventaba etiquetas que el otro no entendía…

📜 El Doctype más largo del mundo

Antes había que escribir esto en cada página:

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN"
  "http://www.w3.org/TR/html4/strict.dtd">

En HTML5 basta con una línea:

<!DOCTYPE html>

✨ Simplificar = menos errores y más compatibilidad

🔥 2004 · La rebelión del WHATWG

Apple, Mozilla y Opera se cansaron y crearon su propio grupo de trabajo

2004 — Nace el WHATWG (Web Hypertext Application Technology Working Group).
2008 — Se publica el primer borrador de HTML5.
2014 — El W3C lo convierte en recomendación oficial. 🎊

🧠 Filosofía HTML5: sé tolerante con los errores y prioriza la compatibilidad

🎊 Octubre de 2014 · ¡Por fin oficial!

2014

El W3C publica HTML5 como recomendación oficial

⏳

Más de una década

Del primer borrador (2008) a la versión oficial pasaron 6 años de revisiones.

🌍

Ya se usaba antes

Muchísimos sitios usaban HTML5 años antes de que fuera "oficial".

🧩 HTML5 no es solo HTML

Es una familia de tres tecnologías que trabajan juntas

🦴

HTML

Estructura
El esqueleto: qué hay en la página.

👕

CSS3

Presentación
La ropa: cómo se ve.

🧠

JavaScript

Comportamiento
Los músculos: qué hace.

📰 Adiós a los <div> por todas partes

HTML5 trajo etiquetas con significado, como las secciones de un periódico

<header> <nav> <main> <section> <article> <aside> <footer>

🤖 Bonus: los buscadores y los lectores de pantalla ahora entienden mejor tu página.
